# Package index

## O sistema visual do site

Os tokens da direção “Boletim Técnico”, adotada pelo site em 2026-08-09.
Existem para que um gráfico ou painel feito em R pouse na página sem que
ninguém tenha de redigitar um hexadecimal.

- [`site()`](https://theoadepaula.github.io/theoviz/reference/site.md) :
  Tokens de cor do sistema visual do site
- [`acento()`](https://theoadepaula.github.io/theoviz/reference/acento.md)
  : Acento unico do site

## Paleta

As cores de série, validadas para daltonismo, e as tintas neutras que
desenham a estrutura da figura. A ordem dos slots faz parte da
validação.

- [`paleta()`](https://theoadepaula.github.io/theoviz/reference/paleta.md)
  : Cores de serie
- [`tinta()`](https://theoadepaula.github.io/theoviz/reference/tinta.md)
  : Tintas neutras
- [`grade_rgba()`](https://theoadepaula.github.io/theoviz/reference/grade_rgba.md)
  : Grade em rgba, para quando o fundo da pagina e desconhecido

## Tabelas

O tema canônico das tabelas gt — régua horizontal apenas, cabeçalho
discreto à esquerda, nenhuma linha vertical. Escolha o modo pela página
em que a tabela vai cair.

- [`tabela_gt()`](https://theoadepaula.github.io/theoviz/reference/tabela_gt.md)
  : Tabela no estilo padrao dos artigos
- [`fmt_br()`](https://theoadepaula.github.io/theoviz/reference/fmt_br.md)
  : Formata colunas numericas em pt-BR
- [`fmt_pct_br()`](https://theoadepaula.github.io/theoviz/reference/fmt_pct_br.md)
  : Formata colunas de percentual em pt-BR

## Números em pt-BR

Milhar com ponto, decimal com vírgula.

- [`num_br()`](https://theoadepaula.github.io/theoviz/reference/num_br.md)
  : Numero em pt-BR
- [`pct_br()`](https://theoadepaula.github.io/theoviz/reference/pct_br.md)
  : Percentual em pt-BR
- [`mil()`](https://theoadepaula.github.io/theoviz/reference/mil.md) :
  Numero em milhares
